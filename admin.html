Real server mode

Sabhi visitors ki bookings aur payments dekhne ke liye server chalayein:

  1. Folder me START-WINDOWS.bat par double-click karein (Mac: start-mac.command).
  2. Email aur password likhein (password kam se kam 8 akshar).
  3. Browser me http://localhost:3000/admin kholein — is page ko file se nahi.
Node.js install hona chahiye: nodejs.org → LTS.
